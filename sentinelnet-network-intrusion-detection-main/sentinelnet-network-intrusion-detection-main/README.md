# SentinelNet
### Real-Time Network Intrusion Detection & Threat Risk Scoring

## Project Overview
SentinelNet is a Machine Learning-based cybersecurity project designed to classify network traffic and identify potential malicious activities.

## Machine Learning Task
Multi-Class Classification.

## Target Classes
- Normal
- DoS
- Probe
- R2L
- U2R

## Dataset
NSL-KDD Dataset.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Plotly

## How to Run

1. Clone the repository.
2. Create a Python virtual environment.
3. Install requirements using:

```bash
pip install -r requirements.txt
```

4. Open the notebook in VS Code.
5. Select the Python environment and run the notebook cells.
