# SentinelNet
## Real-Time Network Intrusion Detection & Threat Risk Scoring

### Project Overview
SentinelNet is a machine learning-based cybersecurity project for classifying network traffic and identifying malicious activities.

### Machine Learning Task
Multi-Class Classification.

### Target Classes
- Normal
- DoS
- Probe
- R2L
- U2R

### Dataset
NSL-KDD Dataset.

### Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Plotly
